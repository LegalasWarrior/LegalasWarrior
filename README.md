# Эларион — текстовая MMO-RPG (прототип)

## Быстрый старт

- Требуется Node.js 18+
- Запуск:

```bash
cd server
npm install
npm run start
# откройте http://localhost:3000
```

## Структура
- `client/` — статический клиент (HTML/CSS/JS)
- `server/` — Node.js сервер (Express + ws)
- `content/` — данные мира
- `docs/` — документация
